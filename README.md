# drawandlearn.app — official site

Static site for **Draw & Learn to Talk with Bob**. Generated by `build.py` (no dependencies), hosted on GitHub Pages, custom domain via Cloudflare.

## Edit
1. Change copy in `build.py` (each page is a Python string).
2. `python3 build.py` → regenerates `index.html`, `*/index.html`, `404.html`, `sitemap.xml`.
3. Commit + push `main`. Pages redeploys in ~1 min.

Preview: `python3 -m http.server 8765` then open http://localhost:8765/.
